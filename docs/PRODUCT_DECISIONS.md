# Product decisions

1. Android 10+
2. Application ID: com.coconutshell.gallerymanager
3. MediaStore public gallery
4. My Albums are virtual app-managed collections
5. Add to Album is separate from physical Move/Copy
6. Private uses protected app-private storage; hidden from normal/system gallery
7. PIN + pattern + device authentication
8. Device authentication recovery
9. 30-day Trash; delete goes to Trash
10. Broad practical Android-decodable image/video support
11. Recent = newest media
12. Non-destructive editing
13. Editable composition project + export
14. Shared content is copied into managed public storage
15. Visual fidelity and functionality equally prioritized
16. No scan every launch by default
17. Actual device folders + smart grouping
18. Newest default; name/date/size/type sorting
19. 2/3/4/5-column grid
20. Explicit selection mode + Select All
21. Replace / Keep Both / Skip conflict prompt
22. Immediate Undo after operations
23. Favorites are virtual
24. Search includes filenames, folders, albums, and metadata
25. Native video playback under custom UI
26. Pinch, double-tap, swipe navigation, swipe-down close
27. Full editor feature set
28. 2–9 photo configurable compositions
29. Preserve original shared filename
30. Notifications only for long operations
31. Full settings surface
